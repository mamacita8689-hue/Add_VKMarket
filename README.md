# Add_VKMarket

Удобная форма для подготовки и публикации товаров в товары сообщества ВКонтакте.

## Что уже есть

- адаптивная форма для компьютера и телефона;
- добавление до 5 фотографий с предпросмотром;
- название, описание, цена, артикул и остаток;
- собственный тип товара для удобной работы с ассортиментом «Город Фантазий 57»;
- поля категории VK и подборки;
- предпросмотр карточки товара;
- проверка обязательных полей;
- сохранение и восстановление черновика в браузере;
- настройки ID сообщества и адреса серверного API;
- подготовленная кнопка «Опубликовать в VK».

## Важно про безопасность

Токен доступа VK нельзя хранить в `app.js`, HTML или `localStorage`. Поэтому интерфейс отправляет товар на отдельный серверный endpoint `/api/products`, а уже сервер должен обращаться к VK API с токеном из переменных окружения.

## Запуск первой версии

Это обычное статическое приложение без сборщика. Можно открыть `index.html` локально или разместить файлы на любом статическом хостинге / GitHub Pages.

## Следующий этап — реальная публикация в VK

Нужно добавить небольшой backend, который:

1. хранит `VK_ACCESS_TOKEN` только на сервере;
2. получает категории и подборки сообщества;
3. загружает фотографии товара через методы VK для фотографий маркета;
4. создаёт товар через VK API;
5. при необходимости добавляет созданный товар в выбранную подборку;
6. возвращает в форму ссылку/ID созданного товара и понятные сообщения об ошибках.

## Файлы

- `index.html` — форма и разметка;
- `styles.css` — оформление и мобильная версия;
- `app.js` — фотографии, предпросмотр, черновики, валидация и подготовка отправки на backend.

## План развития

После подключения публикации можно добавить импорт карточки с сайта `фантазии57.рф`: выбрать товар с сайта → автоматически заполнить название, описание, цену и фотографии → проверить → отправить в VK.
